# 🏛️ Landing Page — Dra. Janaina Medeiros

## ✨ Sobre o projeto

Landing page institucional desenvolvida para a Dra. Janaina Medeiros, advogada especialista em **Direito da Pessoa com Deficiência**, com foco em autoridade, credibilidade e conversão de clientes.

O projeto foi construído com atenção especial à experiência do usuário, performance e boas práticas de SEO, resultando em um site moderno, responsivo e pronto para produção.

---

## 🎯 Objetivos

- Apresentar a profissional de forma clara e estratégica  
- Gerar confiança e autoridade no visitante  
- Facilitar o contato com potenciais clientes  
- Oferecer uma navegação fluida e intuitiva  

---

## 🚀 Funcionalidades

✔ Layout moderno e responsivo  
✔ Navegação suave entre seções  
✔ Botão flutuante de WhatsApp  
✔ Formulário de contato funcional  
✔ SEO otimizado (meta tags + Open Graph)  
✔ Alta performance (Vite + otimizações)  
✔ Design elegante com foco em conversão  

---

## 🛠️ Tecnologias utilizadas

- ⚛️ React  
- ⚡ Vite  
- 🎨 Tailwind CSS  
- 🎞️ Framer Motion  
- 🎯 Lucide Icons  

---

## 📸 Seções do site

- Hero (apresentação principal)
